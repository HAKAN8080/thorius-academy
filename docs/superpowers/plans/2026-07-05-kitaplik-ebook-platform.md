# Kitaplık E-Kitap Platformu — Uygulama Planı

**Goal:** `kitaplik.thorius.com.tr` üzerinde basılı + e-kitap satışı; e-kitap için indirilemez, sayfa çevirmeli okuyucu.

**Architecture:** Mevcut `thorius-academy` reposuna `kitaplik` site modu; WooCommerce/PayTR ödeme; `library_books` + `ebook_entitlements` Supabase; PDF sayfaları yetkili API üzerinden; `react-pageflip` okuyucu.

**Tech Stack:** Next.js 14, Supabase, pdfjs-dist, react-pageflip, WooCommerce webhook.
